### 2. Estrutura de Dados de Métricas (Baseado em `MetricsCard` e `useRestaurantProfile`)

A Dyad deve replicar a estrutura de dados que contém `visitors` e `followers` no perfil do restaurante.

```typescript
// Estrutura de Perfil do Restaurante (Simplificada)
interface RestaurantProfile {
    // ... outros campos
    visitors: number; // Métrica 1
    followers: number; // Métrica 2
    // ... campos de localização (address, city, latitude, longitude)
}
```

### 3. Hooks de Acesso a Dados (useRestaurantProfile, useNearbyRestaurantsByRole)

A Dyad deve replicar a **funcionalidade** desses hooks, que provavelmente fazem chamadas ao Supabase para buscar os dados:

*   **`useRestaurantProfile`**: Busca o perfil do restaurante logado, incluindo `visitors` e `followers`.
*   **`useNearbyRestaurantsByRole`**: Busca restaurantes próximos (usando a localização do restaurante ou a localização atual do usuário) com base em um `maxDistanceKm` e um `requiredRole` (ex: 'premium_restaurant'). A Dyad deve replicar a lógica de **cálculo de distância geográfica** e **filtragem por raio**.
